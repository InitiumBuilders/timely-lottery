// Reference

        
Build on Dash Platform

        

          
🪪 Identity-First Architecture▼
Always start with DPNS. Every action ties to a verifiable identity. Register your identity first with platform.identities.register(), then register a DPNS name.

          
📄 Data Contract Design▼
Keep contracts small and focused. One contract per domain. Version with $format_version. Think of each data contract as a microservice.

          
🧪 Token Testing Workflow▼
Testnet → audit config → mainnet. Always. Use Dash Platform Explorer to verify your token config before mainnet deployment.

          
💰 Fee Structure Strategy▼
Token-based fees create a burn mechanism. The sweet spot: fees low enough that casual users don't notice, but high enough for meaningful supply reduction.

          
🗳️ Group Authorization Patterns▼
3-of-5: 5 members, each power 1, threshold 3. Majority: N members, threshold = ceil(N/2). Supermajority (67%): Multiply powers by 100, threshold 67×N. Max 256 members, 65,536 power each.

          
♾️ Perpetual Distribution Design▼
Configure halving schedules and emission curves in JSON. Set distributionType: "perpetual" with block-based release intervals. Start aggressive, then taper.
